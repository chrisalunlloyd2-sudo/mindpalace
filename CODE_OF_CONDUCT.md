# CODE_OF_CONDUCT.md — the palace's house rules

## Our standard

Everyone in the palace — the Architect, the agents, every contributor —
works under one doctrine: **nothing lives forever, nothing runs for free,
always advancing.** Contributions of every size move the program forward.
What we ask in return is honesty and respect, in both directions.

## Expected behavior

- **Evidence first.** Claims about what works ship with proof — a build
  line, a selftest RESULT, an E2E screenshot, a step-log entry. In
  disputes, evidence wins; seniority doesn't.
- **Respect the cascade.** Changes land through build → selftest → E2E →
  step-log. Nobody bypasses the gate — not maintainers, not the agents.
- **Kind, direct feedback.** Say what you observed and what you expected.
  Reviews critique code and evidence, never people.
- **Credit precisely.** Name who found a bug, who fixed it, who tested it.
  Release notes carry those names.
- **Help the next person.** If you hit a gotcha, it becomes a DEV_SETUP.md
  row. Your stumble is someone's shortcut.

## Unacceptable behavior

- Harassment, personal attacks, or deliberate intimidation of any
  community member.
- Publishing others' private information without consent.
- Presenting unverified claims as evidence (this is an evidence-based
  project; doing so erodes the thing that makes it work).
- Spam, self-promo without contribution, or arguing to win rather than
  to ship.

## Scope

These rules apply in the repo (issues, PRs, discussions, code), the
step-log (#9), and any project-run channels. Off-platform harassment
affecting community members falls within scope when reported.

## Enforcement

- Maintainers may remove, edit, or reject contributions that violate
  this document — comments, PRs, or discussions — with a stated reason.
- **Report to the maintainer** via any of (pick what you're comfortable with):
  - GitHub Discussions: the [Q&A category](https://github.com/chrisalunlloyd2-sudo/mindpalace/discussions/categories/q-a) — public questions, visible to all
  - Issue contact: open a GitHub issue on `chrisalunlloyd2-sudo/mindpalace` marked `question`
  - GitHub profile contact: [chrisalunlloyd2-sudo](https://github.com/chrisalunlloyd2-sudo) — "Start a conversation" sends email without exposing your address
  - Direct email: available on request via the profile contact (kept off public docs to avoid spam harvesters)
  Reports are handled privately and promptly. The full contact map also
  lives in [.github/SUPPORT.md](.github/SUPPORT.md).
- Escalation: repeated violations → temporary mute → permanent ban.
  One strike for evidence-faking; the step-log is sacred.
